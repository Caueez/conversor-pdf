# Contratos

## Objetivo
Definir governanca de contratos e apontar para os contratos de cada servico.

## Escopo
Regras de evolucao de contratos externos e internos no monorepo.

## Regras De Governanca

- Toda mudanca de contrato deve ser documentada junto com o codigo.
- Mudancas de quebra exigem plano de migracao e comunicacao.
- Contratos de API devem permanecer na documentacao de cada servico.
